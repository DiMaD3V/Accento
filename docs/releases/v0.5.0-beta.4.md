# Accento 0.5.0-beta.4

Windows x64 and universal macOS prerelease. Downloads are publicly available on GitHub. This beta continues the test cycle before stable 0.5.0.

## Changes

- Unified app bar and sidebar based on the reviewed Figcraft: one app name, small logo, status and version in the app bar, and bottom-aligned Enable / Disable and Exit actions with discreet red/green colors.
- Available characters has separate heading checkboxes for languages and special sets. Partial selection is visible; global selection and character-search controls are removed. Interface-language search remains available.
- Opt-in **General → Launch at login** starts Accento in the background without opening settings. It applies immediately and is separate from the other preferences’ Save/Discard draft. Windows registration is per-user, quotes executable paths with spaces and respects Task Manager disablement; macOS uses a user LaunchAgent.
- Individual currency selections (initially only €), top/bottom popup position and the current language catalog are included. Languages without additional characters remain available for the interface and are omitted from character-set selection.
- Custom minimize, maximize/restore and close controls retain unsaved-draft protection. Closing settings keeps the input process running.

## Downloads

- `Accento_0.5.0-beta.4_windows-x64-setup.exe`: current-user installer; downloads WebView2 if necessary.
- `Accento_0.5.0-beta.4_windows-x64_portable.zip`: extract all files; requires an existing WebView2 runtime.
- Universal macOS DMG and `Accento_0.5.0-beta.4_universal_macos.zip`: Intel and Apple Silicon, macOS 13+.
- `SHA256SUMS.txt`, `TEST-MACOS.it.txt` and architecture-specific Mac verification reports.

For portable copies, disable launch at login before moving or deleting the application; enable it again from the new copy if needed.

## Verification and beta scope

The source is checked with Rust tests, Clippy, 19 browser scenarios, 28 intentional visual baselines and accessibility checks. Windows native integration covers real WebView/Rust IPC, preferences, launch-at-login state in an isolated profile, custom window controls and close protection. The Windows registry test uses a private non-startup key; background launch is checked from a path containing spaces without enabling the user's real login entry.

Mac packages are built and checked by the universal workflow and the same packaged app is checked on Apple Silicon and Intel. These checks keep input hooks disabled and do not certify a real logout/login, live typing or permission recovery. Follow the included Mac test checklist before relying on those behaviors.

Windows binaries are unsigned; Mac uses an ad-hoc signature and is not notarized. Translations are drafts. Existing beta limitations for clean-machine installation, layouts, IMEs, protected fields, remote sessions, accessibility and real login cycles remain. Linux packages are deferred. No automatic updater is included.
